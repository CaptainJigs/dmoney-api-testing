dMoney API Documentation

Road to SDET Batch 20 - Integration testing with Postman. Base URL: http://localhost:5000. Generated from the Postman collection.

Overview

Road to SDET - Batch 20 - API testing assignment.

End-to-end flow: create 2 customers, 1 agent and 1 merchant; activate them with admin; SYSTEM deposits 5000 tk to agent; agent deposits 2000 tk to customer 1 (commission asserted); customer 1 sends 1000 tk to customer 2 (fee asserted); customer 2 cashes out 500 tk (fee asserted); customer 2 pays 400 tk to merchant (fee asserted).

Each negative test runs before its positive test so a failure cannot break the chain.

Authentication

Protected endpoints need Authorization: Bearer <token> and X-AUTH-SECRET-KEY: {{partnerKey}}. Admin and SYSTEM receive a token from /user/login; Customer, Agent and Merchant receive a token from /user/verify-otp after login.

Fee rules asserted

Agent deposit commission2.5% of amount
Send money feeflat 5 tk
Cash out fee1% of amount, minimum 5 tk
Payment fee1% of amount, minimum 5 tk

Uses the server's dev OTP bypass (?env=dev + DEFAULT_OTP from the server .env), so Newman can run without typing OTPs.

Headers

Content-Typeapplication/json

Body

{
    "identifier": "{{agentPhone}}",
    "otp": "{{defaultOtp}}"
}
Tests
const jsonData = pm.response.json();

pm.test("Status code is 200", function () {
    pm.response.to.have.status(200);
});
pm.test("Login successful with role Agent", function () {
    pm.expect(jsonData.message).to.eql("Login successful");
    pm.expect(jsonData.role).to.eql("Agent");
    pm.expect(jsonData.token).to.exist;
});

if (jsonData.token) {
    pm.collectionVariables.set("agentToken", jsonData.token);
}

X-AUTH-SECRET-KEY{{partnerKey}}

    "from_account": "{{agentPhone}}",

}

    pm.response.to.have.status(201);

    pm.expect(jsonData.message).to.eql("Deposit successful");

});

    pm.expect(jsonData.currentBalance).to.eql(5000 - amount + expectedCommission);
});
